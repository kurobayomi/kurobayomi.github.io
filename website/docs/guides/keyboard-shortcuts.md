# Keyboard shortcuts

On a title's page, press **F1** or **?** to see the shortcuts of that page.

## Everywhere

| Key | Action |
| --- | --- |
| Esc, Alt+←, mouse back button | Go back |
| Ctrl+Shift+O | Link an anime or manga folder |

## Library

| Key | Action |
| --- | --- |
| Ctrl+A | Select all |
| Ctrl+I | Invert the selection |
| Delete | Act on the selection |
| Ctrl+Page Up, Ctrl+Page Down | Previous or next category |
| F5 | Update the category you are viewing |

In the Library, in Browse and in a title's episode or chapter list, drag from an empty spot to select everything the box
touches. Hold **Ctrl** while you start the drag to add to the selection.

## Browse

| Key | Action |
| --- | --- |
| Ctrl+1 | Anime sources |
| Ctrl+2 | Manga sources |
| Ctrl+click | Select or unselect a title |
| Shift+click | Select a range |
| Ctrl+A | Select all loaded titles |
| Ctrl+I | Invert the selection |
| Esc | Clear the selection, then close the search, then leave the page |

## Title page

| Key | Action |
| --- | --- |
| ↑, ↓ | Move in the episode or chapter list |
| Enter | Open the focused episode or chapter |
| Space | Select or unselect the focused one |
| Shift+click | Select a range |
| Ctrl+click | Select or unselect one |
| Ctrl+A | Select all |
| Ctrl+I | Invert the selection |
| Esc | Clear the selection |
| F | Filters |
| R, Ctrl+R | Refresh |
| Ctrl+M | Migrate (titles in your library) |
| F1, ? | Show these shortcuts |

## Updates

| Key | Action |
| --- | --- |
| Ctrl+A | Select all |
| Ctrl+I | Invert the selection |
| Esc | Clear the selection |
| Enter | Open |

## Player

| Key | Action |
| --- | --- |
| Space | Play or pause |
| ←, → | Back or forward 10 seconds |
| Shift+←, Shift+→ | Back or forward 60 seconds |
| ↑, ↓ | Volume up or down |
| F | Full screen |
| Esc | Leave full screen, then the player |
| Click | Play or pause |
| Double-click | Full screen |

## Reader

| Key | Action |
| --- | --- |
| ←, →, Page Up, Page Down | Previous or next page |
| Space, Shift+Space | Next or previous page |
| Ctrl+←, Ctrl+→ | Previous or next chapter |
| Home, End | First or last page |
| +, − , 0 | Zoom in, zoom out, reset zoom |
| Menu key | Show or hide the menu |
| F11 | Full screen |
| Esc | Close a sheet, then full screen, then the reader |
| Ctrl+D | Bookmark the chapter |
| Ctrl+C | Copy the page |
| Ctrl+S | Save the page |
| Shift+F10 | Page actions |

In **Webtoon** mode the arrow keys and the space bar scroll instead of turning pages.
